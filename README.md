On-Offboarding Frontend
React-applikation för hantering av on- och offboarding av personal, med rollbaserad åtkomstkontroll via Azure AD.
Stack: React 19 · Vite · React Router v7 · Azure MSAL · Font Awesome

Förkrav

Node.js ≥ 20
CoreFlow API igång lokalt
Azure AD-appregistrering (klient-ID och tenant-ID)


Kom igång
git clone https://github.com/On-Offboarding/on-offboarding-frontend.git
cd on-offboarding-frontend
npm install
